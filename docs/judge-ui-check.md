# Проверка простого интерфейса для жюри

Дата: 23.09.2026. Проверка локальная, на синтетических данных.

## Изменение

Первый экран — «Демонстрация»: готовый редактируемый пример и одна кнопка «Проверить».
Используются существующие `/demo/mask` и `/demo/unmask` с профилем `autocheck`.
Результат показывает маску, восстановленный текст и фактическое сравнение с исходным.
Измеренное время — полный цикл из браузера, включая оба HTTP-запроса; это не нагрузочный benchmark.
Выбор потребителя и ключи остаются в расширенной проверке через «Инструменты».
Backend, правила авторизации и официальный `/process` не изменены. LLM в простой демонстрации не вызывается.

## Выполненные проверки

- PASSED: `cd frontend && npm run build` — TypeScript и production-сборка Vite, exit 0.
- PASSED: `.venv/bin/pytest -q tests/integration/test_api.py tests/integration/test_g6_ui.py` — exit 0. Есть предупреждения об устаревающих API Starlette/httpx/anyio.
- PASSED: первый вход в браузере на `http://localhost:5173/`: пример заполнен, ключ и выбор профиля не требуются, инструменты свёрнуты.
- PASSED: на стандартном примере найдены три фрагмента; отображается маска и точное восстановление.
- PASSED: текст без ПД — ноль фрагментов и точное восстановление, без сообщения об отключённой модели.
- PASSED: редактирование очищает прежний результат; только пробелы отключают кнопку запуска.
- PASSED: `Ctrl+Enter` запускает проверку.
- PASSED: ввод 1 048 577 ASCII-символов вызывает видимую ошибку «Текст слишком большой»; возврат примера и повторная проверка успешны.
- PASSED: расширенная проверка доступна, защищённый профиль продолжает показывать поле ключа; серверные проверки доступа проходят в указанных тестах.
- PASSED: при ширине viewport 390 и 1440 пикселей ширина документа совпадает с viewport. В обычном размере выполнен визуальный просмотр; временный viewport сброшен.
- PASSED: `/health` на порту 8000 возвращает `ready: true`; `/` отдаёт HTML с актуальным production-бандлом.
- REVIEWED: сброс и размонтирование компонента инвалидируют устаревшие ответы; несовпадение и ошибка восстановления не показывают успешный результат. Искусственная подмена ответа восстановления в браузере не выполнялась.

## Границы проверки

Это проверка нового пользовательского сценария, не повторный полный аудит проекта.
Полный pytest, Redis/multiworker, нагрузка и внешняя модель в этом проходе не запускались.
Неуспешные запросы показаны на экране, но отдельная запись об их ошибке в журнал интерфейса пока не добавляется.
Архив сдачи не пересобирался; перед передачей жюри потребуется собрать его из актуальных исходников.
