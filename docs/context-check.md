# Проверка контекста персональных данных — 23.09.2026

## Требование и выбранное поведение

`ds.pdf`, страница 3, раздел 4.1, исключает из персональных данных публичное упоминание поэта Александра Пушкина и адрес отделения банка. Критерий 3.3 в `Критерии_оценивания _альфа.pdf`, страница 2, оценивает контекстные ловушки и вариации. Это не универсальное исключение для любой записи с известной фамилией.

Проектное решение: непосредственно связанные признаки клиента, анкеты, реквизитов или банковского действия имеют приоритет перед публичным контекстом. Оно согласуется с R15 в `rules.md`; конкретная система приоритетов не объявляется правилом организаторов.

| Сценарий | Проверенное поведение |
| --- | --- |
| Упоминание поэта Александра Сергеевича Пушкина и романа «Евгений Онегин» | Имя и название остаются открытыми |
| Клиент с тем же именем, телефоном и картой | Полное имя, телефон и карта скрываются |
| Вариант «Александер Сергеевич Пушкин» в клиентской записи | Скрывается всё имя, без оставшегося первого слова |
| Клиент читает произведения Пушкина | Имя клиента скрывается, упоминание автора сохраняется |
| «Иван Петров написал мне» | Обычный глагол не превращает человека в публичную личность |
| Дата/место рождения публичного автора и клиента в соседних предложениях | Публичный контекст не переносится на клиента |

## Исправления

- Ограниченная грамматика имени, отчества, фамилии и инициалов заменяет произвольные последовательности слов. Сохраняются исходные координаты и точное восстановление.
- Контекст прикрепляется к конкретному имени, учитывает падежи и не проходит через границы предложений. Клиентские признаки имеют приоритет.
- Небольшой список исторических идентичностей поддерживает упоминания без явного слова «поэт»; это не исключение по одной фамилии. Другие публичные упоминания определяются по локальному контексту.
- Детекторы повествовательной даты и места рождения используют ту же классификацию субъекта. Явные анкетные поля продолжают защищаться.
- На первом экране React добавлены четыре готовых примера без дополнительной настройки и без API-ключа. Смена примера очищает предыдущий результат.
