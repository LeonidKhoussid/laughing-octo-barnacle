# Требования — AlfaGen PII Gateway

> Актуальное сопоставление с полным ТЗ от 23.09.2026: [requirements-verification.md](requirements-verification.md). Ниже сохранены исторические этапы и их результаты; старые утверждения о завершении, отсутствии Приложения A, regex-only детекции и оценочные 100k не являются текущим статусом.

Статусы: `OFFICIAL` (ТЗ/рубрика), `CLARIFIED` (уточнение организаторов), `PROJECT` (проектное решение), `UNKNOWN` (не подтверждено).

## 2. Уточнения организаторов

| Уточнение | Источник | Статус |
| --- | --- | --- |
| Фиксированного эталона маски нет; сравнивается качество скрытия относительно исходной строки | [S5.1] | CLARIFIED |
| Автопроверка дополняет экспертную оценку; прямой формулы перевода в 30 баллов нет | [S5.2] | CLARIFIED |
| SLA — ориентир на ТЗ (1 сек); mean/p50/p95/p99; 0,5 с из PDF не подтверждённый жёсткий порог | [S5.3] | CLARIFIED |
| 1000 RPS — любые запросы к сервису, не 1000 пар/с | [S5.4] | CLARIFIED |
| `payload_id` уникален для пары mask–unmask, кроме повторов после ошибки/429 | [S5.5] | CLARIFIED |
| Исключение из авторизации относится только к контракту автопроверки | [S5.6] | CLARIFIED |
| Демонстрационный ответ LLM допустим; в автопроверке восстановление перефразированного текста не требуется | [S5.7] | CLARIFIED |
| Лишние маски штрафуются слабее пропусков; полное маскирование строки с обычным текстом штрафуется | [S4] | CLARIFIED |
| Default — полная замена чувствительного значения | [S4] | CLARIFIED |
| Длина токена не обязана совпадать с длиной исходного фрагмента | [S4] | CLARIFIED |
| Разделители внутри значения можно сохранять или скрывать; лишнее скрытие служебных слов штрафуется | [S4] | CLARIFIED |
| Известный профиль нагрузки: ~330 RPS среднее, пики до 1000, до 200 соединений; 429 учитывается статистически | [S4] | CLARIFIED |
| Равное число mask/unmask не гарантировано в каждый момент; тестировать mask-heavy | [S4] | CLARIFIED |
| BERT как локальная модель внутри сервиса отдельно разрешён | [S4] | CLARIFIED |
| AlfaGen разрешён для демонстрационного вызова LLM; параметры API из выданного подключения | [S4] | CLARIFIED |
| Сосредоточиться на тексте, а не OCR/base64 | [S4] | CLARIFIED |
| Проверка кода считается успешной в любом случае; подробного отчёта нет | [S4] | CLARIFIED |
| Только предоставленный DeepSeek, VS Code, Kilo Code; иные генеративные провайдеры запрещены | [S6] | CLARIFIED |

## 6. Примечание о необязательных материалах

- Отсутствие PDF критериев не обнуляет их изложение в мастер-промпте; требования используются с указанием источника, оригиналы сверяются при появлении.
- `.env.example` — создаваемый нами файл с безопасными заглушками; его отсутствие не является условием ожидания организаторов и не блокирует разработку ядра.
- Доступ к AlfaGen нужен только для необязательного реального LLM-демо; базовое демо с явно отмеченным имитатором (stub) работает без ключа.
