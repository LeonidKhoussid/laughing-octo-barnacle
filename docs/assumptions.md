# Допущения — AlfaGen PII Gateway

Проектные допущения и неизвестные условия. Не являются правилами конкурса.

## Подтверждённые допущения

- Внутренние offsets — Unicode code points исходной Python-строки, `[start, end)`.
- Default-маска — полная типизированная замена чувствительного значения.
- Токены — криптографически случайные, не менее 128 бит случайности, ограничены контекстом.
- Multiworker требует общего Vault (Redis); fallback Redis → локальная память запрещён.
- Сохраняемый mapping защищается AEAD (AES-GCM) с корректным nonce и associated data.

## Неизвестные условия (требуют уточнения)

- Полное Приложение A (JSON-схема POST /process) — MISSING; блокирует только подтверждение совместимости официального адаптера.
- Точная формула span-метрики и «95%».
- Распределение длин текстов.
- Проверяется ли 100k одновременно с максимальным RPS.
- Ограничения CPU/RAM/GPU.
- Максимальный интервал между mask и unmask.
- Гарантии длительности повторов.
- Точная часовая зона дедлайна.
- Срок обязательной доступности URL после сдачи.

## Допустимость внешнего планирующего документа

- Отдельного ответа организаторов о заранее подготовленных промптах нет.
- Это не подтверждённое разрешение и не отдельно установленный запрет.
- Требование письменного разрешения до начала работы было авторской интерпретацией первой версии, а не цитатой организатора; в версии 2 оно не является автоматическим стоп-фактором.
- Разработка начинается сразу, без повторного вопроса «начать ли разработку?».

## Решения, принятые на этапе G0

- Стек: Python, FastAPI, локальные детекторы, Redis для общего состояния, простой интерфейс без внешних CDN (проектный выбор).
- Начать с минимального вертикального среза (G1) до полной архитектуры; разработка начинается немедленно.
- Отсутствие Приложения A блокирует только подтверждение совместимости официального адаптера; независимое ядро, demo API, детекторы, токенизация, Vault, round-trip и тесты продолжаются. Официальный адаптер помечается UNVERIFIED.
- `.env.example` создаётся нами с безопасными заглушками; его отсутствие не блокирует разработку.
- Демо использует явно отмеченный имитатор (stub); реальный вызов AlfaGen необязателен и не блокирует базовое демо.
